# CL-07 — Диагностика на стороне клиента: «туннель молчит» за 30 секунд

| | |
|---|---|
| Область | клиенты + бот |
| Приоритет | P1 |
| Статус | open |
| Зависимости | CORE-03 (автореконнект), CORE-01/02 (природа зомби) |
| Апстрим | наш опыт: зомби-сессии лечатся только переподключением клиента |
| Источник | **наш опыт**: зомби-кейсы (CORE-01/02) + вопрос админа 2026-10-18 про текст «Узел не может пройти проверку» в приложении |

## Проблема

Главный пользовательский симптом наших известных гонок: «подключено»,
а интернета нет (дата-плейн молчит). Юзер не отличает это от «нода
умерла» и пишет админу. Клиенты не показывают: есть ли хендшейк,
идёт ли трафик, сколько секунд без данных. Кнопки «перезапустить
туннель» может не быть (зависит от платформы) — а именно она лечит
зомби.

## Ожидаемый результат

- [ ] на каждой платформе юзер за 30 секунд видит: подключён ли
      хендшейк, идёт ли трафик (байты), когда последний ответ ноды;
- [ ] есть явное действие «переподключить туннель» (или эквивалент),
      задокументированное в FAQ как первое средство;
- [ ] бот `/status` синхронизирован с этим словарём: FAIL-проверки
      говорят юзеру ровно те действия, которые есть в FAQ;
- [ ] критерий успеха: типовой кейс «молчит туннель» решается юзером
      сам, без сообщения админу (проверено на 2 «свежих» юзерах).
