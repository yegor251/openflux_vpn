## Проблема

Desktop-клиент — самый функциональный (мульти-транспорт, встроенный
браузер, визард ноды), но мы его ни разу не открывали. Вопросы:
работает ли с нашими `openflux://`-ссылками и direct-l3; не
конфликтует ли tun-режим с нашим macOS CLI; визард ноды позволяет
юзеру поднять «свою ноду» мимо нас — допустимо ли; на Windows — что
с правами админа и WinTun.

## Ожидаемый результат

- [ ] установлены на всех трёх ОС, проверено: импорт нашей ссылки,
      direct-l3 туннель, выход с IP ноды, SOCKS5-режим;
- [ ] вердикт-документ: рекомендуем ли мы Desktop (и кому: Windows-
      юзерам — точно кандидат), какие режимы включаем в FAQ;
- [ ] риск «визард ноды мимо нас» оценён и решён (ok / прячем в
      инструкции / не рекомендуем);
- [ ] конфликт с CLI-клиентом на одной машине описан (или признан
      несущественным);
- [ ] если рекомендуем — PRD-02 обновлён.
