| Апстрим | ядро собирается под linux (наш `bin/openflux-linux`); Desktop .deb существует |

## Проблема

Linux-путь сейчас рукопашный: собрать бинарь, написать конфиг руками,
запустить sudo. Для продуктового VPN нужен «команда из двух строк»
как минимум. У нас уже есть инструмент генерации ссылок — не хватает
инсталлятора-клиента, который из `openflux://`-ссылки делает рабочий
tun + автозапуск.

## Ожидаемый результат

- [ ] установочный скрипт/пакет: бинарь + юнит (system, для headless;
      и/или user) + конфиг из ссылки; один вход — ссылка;
- [ ] headless-сервер как клиент (домашний роутер/мини-ПК) — рабочий
      сценарий: поднялся при загрузке, переживает обрывы (CORE-03);
- [ ] `/download` содержит проверенную инструкцию для Linux;
- [ ] приёмка на реальном железе (или VM): трафик идёт через ноду,
      DNS внутри туннеля (SRV-07).
