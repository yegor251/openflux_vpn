## Проблема

Android-клиент — самый массовый для наших будущих юзеров, но ни одна
сборка не прогнана против НАШЕЙ ноды: у админа iOS, `/download`
показывает ссылку на релиз по совету апстрима. Не подтверждено даже
базовое: QR из бота сканируется, direct-l3 канал поднимается,
трафик идёт.

## Ожидаемый результат

- [ ] путь целиком на реальном устройстве: `/issue` → QR → туннель
      поднялся → сайты открываются, выход с IP ноды (проверено);
- [ ] DNS внутри туннеля живой (SRV-07), большие загрузки не роняют
      VPN (контекст #17);
- [ ] смена Wi-Fi↔LTE, перезапуск приложения — поведение задокументировано
      (что само, что руками);
- [ ] известные баги целевой версии проверены на нашей конфигурации
      (#39 Android 11, #38 скачивание ядра) — вердикт в /download;
- [ ] итог: в `/download` лежит ссылка на версию, подтверждённую
      приёмкой, а не «свежий релиз».
