## Проблема

Конвейер куков (скилл + `scripts/refresh_cookies.py`) принят на
репетиции, но живёт на честном слове агента: «раз в 1–2 недели
проверить» — никто не напоминает. При этом куки нужны уже сегодня:
бот выпускает док-носители ими (`ya-cookies.txt` на VPS). Их смерть
= выпуск новых каналов встанет, а алерт про это есть только в
watchdog для лейнов, которых в каналах нет.

## Ожидаемый результат

- [ ] напоминание о плановой проверке куков приходит админу
      автоматически (крон агента/бота), а не из памяти;
- [ ] проверка свежести куков включена в health бота: смерть куков =
      алерт админу (сейчас проверяется только для каналов с лейном);
- [ ] процедура обновления отрепетирована повторно end-to-end
      (экспорт юзером → install на VPS → выпуск тестового канала);
- [ ] решение по пулу аккаунтов зафиксировано: отложено до возврата
      посредников (уже в PLAN) — переупомянуто здесь, чтобы не потерять.
