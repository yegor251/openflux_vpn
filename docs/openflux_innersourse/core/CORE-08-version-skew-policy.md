# CORE-08 — Политика несовпадения версий (нода ↔ клиенты)

| | |
|---|---|
| Область | ядро + клиенты |
| Приоритет | P1 |
| Статус | open |
| Зависимости | CORE-07 |
| Апстрим | #183 (striped-обёртка ломает stream-mode со смешанными версиями) |

## Проблема

Клиенты обновляются сами и независимо от ноды (сторы, TestFlight,
APK). Апстрим уже словил ломку на смешанных версиях (#183: striped-
обёртка cupsonline рвёт stream-mode и старых пиров). У нас нет
матрицы «минимальная версия клиента ↔ версия ноды», ссылки
`openflux://` не несут информации о версии, пользователь может сидеть
на клиенте, который нода обслуживать не обязана.

## Ожидаемый результат

- [ ] матрица совместимости в docs: для каждой нашей ноды — диапазон
      поддерживаемых версий клиентов, обновляется вместе с CORE-07;
- [ ] при выпуске новой версии клиентов известен протокол проверки
      «старейший клиент ↔ новейшая нода» и «наоборот» — туннель живёт;
- [ ] у пользователя есть видимый способ узнать, что его клиент
      устарел до несовместимости (сообщение клиента/бота), а не
      «интернета нет»;
- [ ] если формат ссылки позволит нести минимальную версию — требование
      зафиксировано в CL-09 (сам формат не переизобретать).
