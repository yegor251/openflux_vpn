## Проблема

Рестарт ноды под живым клиентом: клиент остаётся в зомби навсегда —
циклит `[CRYPTO] no answer from the peer under KDF context ...`,
сам не восстанавливается. Лечится только рестартом клиента.
Операционно мы требуем «трогал ноду — перезапусти клиент», но
продуктовый VPN так не работает: юзер не должен этого знать.

Ожидаемое поведение: ренегоциация либо успешно восстанавливает
сессию, либо чисто рвёт соединение, чтобы клиент переподключился.
Бесконечный цикл контекстов — худший из исходов.
