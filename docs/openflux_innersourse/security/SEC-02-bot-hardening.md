## Проблема

Бот работает от root: ему нужны systemctl для каналов, запись в
`/etc/openflux-node`, чтение кук и реестра. Root-бот = любая дыра
в aiogram/зависимостях = вся машина (и всё, что в SEC-01). PLAN это
фиксирует как не сделанное. Нужно: минимальный пользователь, точные
разрешения, systemd-сандбокс — и чтобы LocalOps при этом продолжал
работать.

## Ожидаемый результат

- [ ] бот — непривилегированный пользователь; root-действия — через
      узкий whitelist (sudo-правила только на нужные команды или
      поллук с политикой), не «sudo ALL»;
- [ ] юнит-сандбокс включён (ProtectSystem/PrivateTmp/NoNewPrivileges
      и т.п. — насколько совместимо с LocalOps), факт зафиксирован в
      юните;
- [ ] после переезда всё работает: выпуск/rotate/revoke/status из
      бота, watchdog, рестарт при ребуте (drill);
- [ ] известно, какие файлы боту принадлежат, какие читаются —
      владелец/группа расставлены, 0600 сохранён.
