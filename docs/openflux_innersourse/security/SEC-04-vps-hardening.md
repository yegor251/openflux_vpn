## Проблема

VPS — единственная точка, где лежит всё (SEC-01), и при этом его
базовое укрепление не прогонялось: не зафиксировано, какие порты
открыты снаружи, нет подбор-защиты SSH (fail2ban или аналог),
авто-обновления безопасности ОС не настроены/не подтверждены,
журналы не ротируются под наш объём. Сервер «тестовый», но живёт
с реальными ключами.

## Ожидаемый результат

- [ ] снаружи видно ровно ожидаемое множество портов (ssh, каналы,
      всё остальное закрыто) — скан с внешней точки, отчёт в docs;
- [ ] SSH: только ключи (уже так), подбор ограничен (fail2ban/аналог),
      подтверждено рабочей попыткой;
- [ ] security-обновления ОС ставятся автоматически (unattended) и не
      ломают ноды (drill OPS-02);
- [ ] journald с ротацией/лимитом — диск не может быть забит журналами
      (связка с OPS-02);
- [ ] итоговая сводка «что открыто, что защищено, что принято как есть»
      — одна страница в docs, обновляется при изменениях.
