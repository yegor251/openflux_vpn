## Проблема

На VPS `users.json` (все ключи), `bot_users.json`, куки — 0600 root.
На Mac — `out/*.key`, `users.json` локального CLI. Защита — права
файла, т.е. весь уровень = «кто получил root, получил всё» (это
зафиксировано как принятый риск), но **сейчас даже от самого себя**
ничего не защищено: случайный коммит, случайный бэкап, случайная
выкладка. Автопроверок «секрет не утёк в git» нет — только
внимательность агента.

## Ожидаемый результат

- [ ] принято и записано решение по at-rest: шифровать (чем, где
      ключи) или осознанно нет (обоснование: личный круг, диск
      провайдера — тогда хотя бы для бэкапов шифрование обязательно,
      см. SRV-04);
- [ ] pre-commit/CI-проверка: секретные паттерны (hex-ключи длиной 64,
      cookies-строки, токены бота) не попадают в коммит — работает,
      проверено на «нарочно утекшем» файле;
- [ ] инвентарь секретов: где лежит каждый секрет, кто его копия,
      что происходит при его утечке (ссылки на OPS-03);
- [ ] правило маскирования в логах (`openflux://v1/<redacted>`)
      покрыто проверкой: grep по журналам не находит полных ссылок.
