## Проблема

VPS-копия `users.json` (мастер ключей каналов, выпущенных ботом!) и
`bot_users.json` (привязки tg_id↔канал, приглашения) — единственные.
Гибель VDS = потеря всех ссылок пользователей: каналы физически живы,
но перевыпустить ссылки нельзя — ключи есть только там. Плюс
`ya-cookies.txt`. Никаких копий сейчас нет; из-за секретности нельзя
просто scp в git.

## Ожидаемый результат

- [ ] ежедневный зашифрованный бэкап (реестр + bot_users + cookies)
      на машину админа (и/или второй хост); ключ шифрования НЕ на
      том же VDS;
- [ ] восстановление отрепетировано: на чистом каталоге из бэкапа
      поднимается рабочий бот и перевыпускается ссылка реального
      канала (drill, не теория);
- [ ] бэкапы ≥ 2 поколений, контроль успешности (алерт, если бэкап не
      снялся);
- [ ] в бэкапе нет ничего незашифрованного: проверено вскрытием
      архива.
