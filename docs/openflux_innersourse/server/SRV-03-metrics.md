# SRV-03 — Метрики каналов и тренды

| | |
|---|---|
| Область | exit-ноды / наблюдаемость |
| Приоритет | P1 |
| Статус | open |
| Зависимости | CORE-04 (счётчики L3), SRV-01 (норма нагрузки) |
| Апстрим | #83 — формат `[L3-STATS]` уже в ядре |

## Проблема

Наблюдаемость сейчас — точечная: watchdog бота знает «юнит жив /
порт слушается», счётчики `[L3-STATS]` видны только с `Debug = 2`
включённым руками. История отсутствует: нельзя ответить «канал X
тормозит всегда или только вечером», «сколько трафика гоняет юзер Y»,
«нода деградирует или это сеть».

## Ожидаемый результат

- [ ] периодический сбор со всех каналов: unit alive, NRestarts,
      трафик юнита, счётчики L3 (fromTr/toNet/fromNet/toCli + дропы) —
      без постоянного Debug=2 в проде (или с обоснованием, почему ок);
- [ ] хранение ≥ 14 дней на VPS, без роста журналов до гигабайт
      (ротация);
- [ ] сводка по запросу: админ (или бот-команда `/status` в расширенном
      виде) видит трафик и здоровье своего канала за сутки;
- [ ] трендовые алерты в watchdog: канал длительно под дропами > N%,
      нода под memory-pressure, трафик аномально велик (защита от
      «один юзер всё съел» — связка с SRV-02).
