## Проблема

В l3-режиме DNS клиента должен уходить через tun (UDP NAT на ноде),
но проверялся только косвенно: socks5-стенды резолвят на клиенте и
этот путь не трогают. Не доказано: работает ли резолв внутри туннеля
на всех платформах, нет ли утечки DNS (запросы провайдеру мимо
туннеля), что происходит с DNS при doze/смене сети на мобильных.

## Ожидаемый результат

- [ ] на каждом клиенте (CLI, Android, iOS, Desktop) подтверждено:
      резолв имён идёт через туннель (виден на ноде), краш-кейсы
      (длинные имена, DNSSEC, большие ответы/TC-бит) отработаны;
- [ ] тест на утечку DNS: при поднятом туннеле ни один запрос не
      уходит системному резолверу вне туннеля (инструментально);
- [ ] поведение при недоступности DNS на ноде определено: клиенты
      показывают «нет DNS», а не «сайты не открываются» загадочно;
- [ ] если путь где-то сломан — известен workaround (например, DoH
      на клиенте) и он задокументирован в FAQ юзера (PRD-03);
- [ ] пункт снят с «Открытых вопросов» PLAN.md.
