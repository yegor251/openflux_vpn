## Проблема

Боевой VDS — 1 GB RAM. l3-режим ест память заметнее на соединение
(conntrack в userspace). Мы не знаем, сколько каналов тянет сервер до
деградации: PLAN прямо говорит «верхняя граница — измерить в M4».
Планирование «второго сервера» (SRV-05) без этой цифры — гадание.
