## Проблема

Приглашение — единственная дверь в бота: одноразовый токен в
deep-link. Сейчас токены живут вечно (до использования), списка нет,
отзыва нет. Утёкший deep-link (пересланное сообщение) открывает
дверь первому встречному навсегда. Для круга «семья/друзья» риск
малый, но продуктовое качество = управляемая дверь.

## Ожидаемый результат

- [ ] у приглашения есть срок жизни (по умолчанию N дней) и
      одноразовость (уже есть);
- [ ] админ видит список активных приглашений и может отозвать любое;
      отозванное/просроченное deep-link не работает с понятным
      сообщением юзеру;
- [ ] события приглашений (выпущено/использовано/отозвано/просрочено)
      попадают в аудит-лог (SEC-03);
- [ ] лимит на количество живых приглашений (спам-защита от самого
      админа).
