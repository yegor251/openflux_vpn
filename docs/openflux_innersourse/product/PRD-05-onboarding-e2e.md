## Проблема

Всё по кусочкам работает (админ прошёл путь сам), но нет замера и
приёмки «свежий человек без знаний доходит до рабочего VPN сам».
Каждая платформа добавляет свои ступени (скачать APK/Huawei, TF,
QR). Пока этот путь не измерен и не зачищен, каждый новый юзер —
сопровождаемый.

## Ожидаемый результат

- [ ] 3 реальных новых пользователя прошли путь сами: Android, iOS,
      desktop (по одной платформе на человека как минимум);
- [ ] измерено время от deep-link до первого загруженного через
      туннель байта на каждой платформе; целевая планка задана и
      достигнута (например ≤ 15 минут);
- [ ] все спотыкания пути устранены (текст бота, FAQ, ссылки);
      повторный замер подтвердил;
- [ ] сценарий «повторный вход с нового устройства» (телефон потерян)
      проверен: `/my` + QR — работает без админа.
