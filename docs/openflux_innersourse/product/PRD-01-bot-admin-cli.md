## Проблема

Бот намеренно без админ-команд (решено), но часть операций — только
для админа: выпустить приглашение, ротировать/отозвать канал
пользователя (инцидент), посмотреть всех. Сегодня это SSH на VPS и
`python -m oflux_bot.invite` руками; реестр-мастер на VPS, локальный
CLI с ним расходится (это уже попадало в PLAN как ручной пересев).
Каждая такая операция — место для ошибки.

## Ожидаемый результат

- [ ] с машины админа одной командой делаются: выпуск N приглашений,
      список активных приглашений и отзыв, list всех каналов,
      rotate/revoke ЧУЖОГО канала — без запоминания ssh-строк;
- [ ] реестр не расходится: VPS-копия остаётся мастером, CLI читает/
      пишет её по SSH, конфликты исключены конструктивно;
- [ ] деструктивные операции требуют подтверждения (как в боте);
- [ ] операции идемпотентны/безопасны к повтору, всё логируется с
      маскированием ссылок.
