## Проблема

`/download` — витрина: Android-ссылка на релизы GitHub (живая, но не
проверенная приёмкой и не зафиксированная по версии/хешу), iOS —
заглушка «админ даст», macOS — «CLI из репо проекта». Юзер с Huawei
или без доступа к GitHub не может скачать APK вообще. Версию мы не
контролируем: апстрим обновил релиз — наши юзеры получили сборку,
которую никто не проверял.

## Ожидаемый результат

- [ ] для каждой платформы — конкретная проверенная версия (приёмка
      CL-01/03/05/06), а не «свежий релиз»;
- [ ] APK (и Deb/dmg для desktop, если рекомендуем) зеркалятся на
      наш VPS с SHA-256; `/download` отдаёт наше зеркало как
      основной путь, GitHub как запасной;
- [ ] iOS-путь рабочий (CL-03): ссылка/инструкция, доводящая юзера
      до установленного клиента;
- [ ] текст `/download` обновляется одним действием (файл/конфиг),
      а не правкой кода бота;
- [ ] правило зафиксировано: версия в `/download` меняется только
      после приёмки.
