## Проблема

У юзеров нет ни одного документа: что это за VPN, что можно, чего
нельзя, что делать при «не работает». Все знания — в голове админа
и в PLAN/CLAUDE.md (не для юзеров). Типовые случаи предсказуемы:
«подключено, но интернета нет» (зомби), «узел не может пройти
проверку» (наш direct-канал — текст приложения не про нас),
«медленно», «некоторые сайты не открываются».

## Ожидаемый результат

- [ ] FAQ для юзеров (русский, без наших внутренних терминов):
      подключение с нуля на каждой платформе, первые средства
      диагностики (переподключить, проверить /status), когда писать
      админу и что прикладывать;
- [ ] отдельные короткие ответы на топ-симптомы (см. Проблема) —
      так, чтобы бот мог отправлять их одной командой;
- [ ] правила использования: что запрещено (массовая раздача ссылки,
      которая = ключ), лимиты, что происходит при ротации/отзыве;
- [ ] документ живёт в репо и раздаётся ботом; правка FAQ не требует
      релиза бота;
- [ ] проверка «юзер решил свой случай по FAQ без админа» — на 2
      новичках.
