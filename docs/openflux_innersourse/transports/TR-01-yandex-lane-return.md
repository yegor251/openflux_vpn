## Проблема

Яндекс перевёл оба наших IP на SmartCaptcha/login-стены; у headless
exit по дизайну нет пути прохождения капчи (#106). Куки на клиенте
работали, на exit — нет; при каждом флапе мёртвого лейна сессия
уходила в live-lock ренегоциации (CORE-02). Лейн убран из каналов,
док, куки и обвязка сохранены (`scripts/refresh_cookies.py`, скилл
`refresh-cookies`). Критерии возврата сформулированы в
`docs/WHY_MASKING.md`, но не автоматизированы.

      чек (скрипт/агентская рутина), запуск раз в неделю;
