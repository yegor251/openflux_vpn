## Проблема

Mail.ru закрыл анонимный доступ к публичным ссылкам (#193, глобально,
фикса нет) — транспорт мёртв для всех. Модуль `docprovider/mailru`
сохранён, есть даже второй аккаунт-посредник. Возврат возможен либо
откатом политики Mail.ru, либо апстрим-решением с авторизацией —
следить, не изобретать своё раньше времени.

## Ожидаемый результат

- [ ] #193 и связанные (#191, #173, #164, #171) в списке еженедельной
      сводки CORE-07;
- [ ] runbook возврата: что включить в конфиге канала, какой пул
      аккаунтов/кук нужен, как принять на selftest — описан и
      отрепетирован «на сухую» (без боевого включения);
- [ ] при возврате: канал с mailru-лейном живёт сутки на тест-VDS без
      ручного вмешательства;
- [ ] если Mail.ru не вернёт анонимный доступ за квартал — явное
      решение похоронить модуль или перевести на авторизованные куки.
