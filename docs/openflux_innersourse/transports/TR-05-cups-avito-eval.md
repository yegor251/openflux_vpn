## Проблема

В ядре есть два «прочих» посредника: cupsonline (striped-обёртка,
свежая #179) и avito. По обоим открыты свежие баги, в т.ч.
несовместимость версий (#183) и UA-блок (#199). Это потенциальные
бесплатные варианты маскировки — но прежде чем брать, нужно понять,
живы ли они вообще в связке «наша нода node-v1.4.2 + актуальные
клиенты 3.7.x».

## Ожидаемый результат

- [ ] по каждому транспорту — PoC на тест-VDS и verdict-документ с
      логами: поднимается ли сессия, живёт ли дата-плейн;
- [ ] проверена смешанная пара версий (нода 1.4.x + клиент 3.7.x) —
      в контексте бага #183;
- [ ] для avito отдельно: подтверждён или снят UA-блок (#199) на нашей
      конфигурации;
- [ ] живые кандидаты внесены в список маскировочных опций
      docs/WHY_MASKING.md с критериями боевого включения;
- [ ] мёртвые — закрыты записью «проверено YYYY-MM-DD, не работает
      из-за #N» чтобы не переисследовать.
