# Продуктовый бэклог OpenFlux VPN (innersource-задачи)

Каталог — продуктовый бэклог «до продуктового VPN»: ядро, все клиенты
для популярных платформ, серверная часть, эксплуатация, безопасность.
Тактический текущий план — `docs/PLAN.md`; этот каталог — что должно
быть правдой у продукта, независимо от порядка работ.

**Формат задачи:** один файл = одна задача. Обязательные части:
проблема/контекст (с фактами и ссылками) и ожидаемый результат
(чек-лист приёмки). Решения в файлах нет — выбирается при работе
над задачей.

**Статусы:** `open` → `in-progress` → `done` (правится в шапке файла
прямо при работе; в done — дата и ссылка на коммит). Приоритеты:
P0 — надёжность и приёмка того, что уже живёт; P1 — продукт на все
платформы; P2 — устойчивость и расширение; P3 — далеко.

## Карта зависимостей (крупное)

```
CORE-01 (зомби) ── CORE-02 (live-lock) ── CORE-03 (автореконнект)
        └────────── всё остальное опирается на предсказуемый дата-плейн
CORE-07 (мониторинг апстрима) → CORE-08 (версии) → все клиенты
TR-01/03/04/05 (оценки лейнов) → TR-06 (мульти-транспорт+failover) → CL-09 (формат ссылки)
SRV-01 (ёмкость) → SRV-02 (лимиты), SRV-05 (второй VDS)
SRV-04 (бэкап) → SEC-01, OPS-03, любые миграции
PRD-02 (проверенные ссылки) ← CL-01/03/05/06 → PRD-05 (онбординг e2e)
OPS-01 (приёмка M5.5) → OPS-02 (drills) → OPS-03 (playbook)
```
