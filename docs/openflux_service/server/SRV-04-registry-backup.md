## Проблема

VPS-копия `users.json` (мастер ключей каналов, выпущенных ботом!) и
`bot_users.json` (привязки tg_id↔канал, приглашения) — единственные.
Гибель VDS = потеря всех ссылок пользователей: каналы физически живы,
но перевыпустить ссылки нельзя — ключи есть только там. Плюс
`ya-cookies.txt`. Никаких копий сейчас нет; из-за секретности нельзя
просто scp в git.

## Ожидаемый результат

- [x] ежедневный зашифрованный бэкап (реестр + bot_users + cookies +
      bot.yaml/servers.yaml) на машину админа; ключ шифрования НЕ на
      том же VDS (парольная фраза только на Mac, шифрование в потоке);
      `scripts/backup_registry.sh pull`;
- [x] восстановление отрепетировано: drill расшифровывает копию,
      поднимает её в scratch-каталоге на VPS и перевыпускает ссылки
      реальных каналов (2/2, `scripts/restore_drill.py`); полная
      подмена живого каталога бота — в OPS-02;
- [x] 14 поколений, контроль успешности: успешный pull ставит
      `.last-backup` на VPS, watchdog шлёт алерт, если штамп старше
      36 ч; автозапуск по крону Mac — см. шаг пользователя;
- [x] в бэкапе нет ничего незашифрованного: шифрование в pipe,
      roundtrip-проверка каждого архива (`verify`).

## Как пользоваться

```
scripts/backup_registry.sh init    # разово: фраза + каталог
scripts/backup_registry.sh pull    #.daily по крону Mac
scripts/backup_registry.sh verify  # вскрыть последний архив
scripts/backup_registry.sh drill   # восстановление-проверка на VPS
```
