## Проблема

`pick_server` и мульти-VDS код существуют и принимались на selftest,
но в бою один сервер, а бот ходит в ноду через LocalOps (свой хост).
Второй VDS ломает допущения: боту нужен SSH-доступ к чужому серверу,
куки/инсталлятор должны поставляться туда, «мастер реестра на VPS
бота» остаётся ли мастером — не прогонялось.

## Ожидаемый результат

- [ ] runbook ввода второго VDS: инсталлятор, firewall, cookies,
      права бота (SSH-ключ), проверка — по шагам, воспроизводимо;
- [ ] бот выпускает канал на выбранном сервере через SSH-ops и
      показывает в `/status` на каком;
- [ ] ответ на вопрос миграции: переезд канала между серверами без
      смены ссылки возможен (и сделан) — либо невозможен, и описан
      путь «/rotate + новая ссылка юзеру» с уведомлением;
- [ ] балансировка проверена: два сервера, перегрузка первого → новые
      каналы идут на второй; отказ одного сервера виден алертом.
