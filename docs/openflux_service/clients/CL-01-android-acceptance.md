## Проблема

Android — самая массовая платформа юзеров, но ни одна сборка не прогнана
против НАШЕЙ ноды. Team-сборки 3.10.x несут новое ядро (закрытые
зомби/live-lock, «network watch follows the real networks») — ожидания
поменялись: рестарты ноды и смена сетей должны переживаться сами.

## Ожидаемый результат

- [ ] путь целиком: `/issue` (или `/my`) → QR → туннель поднялся →
      сайты открываются, выход с IP ноды;
- [ ] DNS внутри туннеля живой; большие загрузки не роняют VPN;
- [ ] смена Wi-Fi↔LTE и перезапуск приложения — восстановление само,
      без ручного переподключения;
- [ ] рестарт ноды под подключённым клиентом → клиент оживает ≤60 c
      (наш замер на CLI: t+9 c; на Android проверить);
- [ ] итог: версия 3.10.3 зафиксирована в `/download` (PRD-02).

## Регресс-чек-лист на каждую новую сборку (15 минут)

Установить → QR из `/my` → трафик → рестарт ноды (ssh) → трафик вернулся
сам → смена сети → трафик вернулся сам.
