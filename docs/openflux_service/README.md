# Бэклог нашего сервиса (`openflux_service`)

Всё, что делается **внутри нашего проекта**: oflux-admin, oflux_bot,
форк инсталлятора, VPS и его эксплуатация, безопасность, дистрибуция
клиентов пользователям. Работа в чужих репозиториях (ядро OpenFlux,
Android/iOS/Desktop, транспорты апстрима) — в соседнем каталоге
`docs/openflux_innersourse/`.

Формат задачи, статусы и легенда пометки «Источник» — те же, что в
innersourse README (в каждой задаче шапка-таблица + проблема +
чек-лист ожидаемого результата). Префиксы ID сохранены как есть
(CORE-06/07, TR-06/07 живут здесь, хотя начинались в общем бэклоге) —
чтобы не сломать перекрёстные ссылки между задачами.

**Колонка MVP** — по критериям админа (удобство клиента, скорость,
стабильность соединения): `да` = обязателен до запуска для
посторонних пользователей, `желат.` = заметно влияет, но не блокер,
`нет` = после запуска.

## Критический путь MVP

```
SRV-04 (бэкап реестра) → OPS-01 (алерты) → SRV-06 (решение A/B)
   → CL-01 (Android) + CL-03 (iOS) + PRD-02 (/download)
   → PRD-03 (FAQ) + PRD-05 (онбординг e2e)
Параллельно в апстриме (CORE-02/CORE-03, см. openflux_innersourse):
   компенсация до фикса — CL-07 + PRD-03.
```
