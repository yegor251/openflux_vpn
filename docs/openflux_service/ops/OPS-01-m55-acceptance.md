## Проблема

M5 (бот) принят частично: выпуск/rotate/revoke юзером проверены,
но алерты не проверены ни разу живым тестом, массовый сбой не
симулировался, второй реальный пользователь не заходил. Кроме того,
висит решение A/B по авто-апдейту (SRV-06).

## Ожидаемый результат

- [ ] живой тест алертов: остановлен юнит канала → 🔴 в личку админа
      после 3 проб, запущен → 🟢; кулдауны проверены;
- [ ] массовый сбой симулирован (≥50% каналов разом) → ровно один
      агрегированный алерт;
- [ ] протухание кук симулировано → алерт + напоминания по расписанию,
      обновление через скилл гасит алерт;
- [ ] второй реальный пользователь зарегистрирован по приглашению и
      работает (частично закрывается PRD-05);
- [ ] решение A/B по авто-апдейту принято (или переезжает в SRV-06
      с датой);
- [ ] чек-лист M5.5 в PLAN.md полностью [x].
