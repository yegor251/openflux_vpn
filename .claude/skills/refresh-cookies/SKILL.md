# Обновление куки Яндекса (полуавтомат)

Куки логина (`Session_id`/`sessionid2`) имеют календарный срок до 2027,
но Яндекс отзывает их внезапно (логин с другого устройства, антифрод).
Живая проверка — единственный критерий. Скрипт: `scripts/refresh_cookies.py`.

## Процедура

1. **Проверка** (безопасно, без секретов в выводе):
   ```
   .venv/bin/python scripts/refresh_cookies.py check
   ```
   - `OK` — всё живо, ничего не делаем (сообщи дату проверки).
   - `FAIL` — переходи к шагу 2.

2. **Запросить у пользователя свежий экспорт.** Пользователь не знает,
   на какие сайты ходить — отправь ему план из секции
   «Шаблон сообщения пользователю» ДОСЛОВНО (можно дополнять, но не
   урезая шаги). Жди «готово», не запускай install раньше.

## Шаблон сообщения пользователю ( отправлять целиком )

**Что делать в браузере (5 минут)**

1. **Открой Chrome** (тот же, где стоит расширение экспорта кук —
   «Get cookies.txt LOCALLY», уже установлено).
2. **Зайди на `https://yandex.ru`** и убедись, что ты логинен под тем же
   аккаунтом Яндекса, которым пользовался на `docs.yandex.ru`
   (владелец доков-носителей). Другой аккаунт или не залогинен —
   сначала войди под нужным.
3. По желанию, для верности: открой `https://docs.yandex.ru` — страница
   должна открыться без логина. Тогда в куках гарантированно свежая
   сессия.
4. Иконка расширения **«Get cookies.txt LOCALLY»** → экспорт **текущего
   сайта** (`yandex.ru`), формат **Netscape** (по умолчанию).
5. Скачанный файл переименуй в **`fresh-cookies.txt`** и положи в корень
   репы: `/Users/macbook/PycharmProjects/openflux_vpn/fresh-cookies.txt`.
6. Напиши агенту **«готово»**.

Дальше всё делает агент: `install` отклонит битый/чужой экспорт, ничего
не сломав; старые куки уйдут в бэкап; ноды тронуты не будут, если у
каналов нет яндекс-лейна.

3. **Установка** (после «готово»):
   ```
   .venv/bin/python scripts/refresh_cookies.py install fresh-cookies.txt
   ```
   Скрипт сам: провалидирует экспорт живой проверкой (плохой — отклонит,
   ничего не меняя), забэкапит старые, обновит `ya-cookies.txt`,
   пересоберёт `out/cookies-yandex.json`, засеет сторы нод ТОЛЬКО для
   каналов с яндекс-лейном (с рестартом юнита — клиенты таких каналов
   должны переподключиться; скрипт это напечатает).

4. **Проверка результата**: повторный `check` → `OK`; если перезапускались
   юниты — `oflux-admin doctor <канал>` по каждому затронутому.

5. **Приборка**: предложить пользователю удалить `fresh-cookies.txt`.

## Правила

- Значения кук НЕ печатать и не вставлять в логи/коммиты — только имена
  кук и счётчики. Все cookie-файлы 0600 и в .gitignore.
- Если пользователь экспортировал куки НЕ под тем аккаунтом (не владельца
  доков) — install провалится на живой проверке; сообщи и попроси
  повторить под нужным аккаунтом.
- Не запускай install, пока пользователь не подтвердит, что файл положен.
- После install с рестартами нод напомни: клиентам нужен реконнект
  (см. CLAUDE.md «Известные гонки апстрима»).
